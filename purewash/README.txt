Pure Wash: Satisfying ASMR — Privacy Policy for GitHub Pages
==============================================================
Place the file at this exact path in the ROOT of your GitHub Pages website repository:

purewash/privacy/index.html

The /purewash/privacy/ URL will then serve index.html if the website is configured for that repository root.

Example custom-domain URL (only if publicvoid.win is configured as the Pages host):
https://publicvoid.win/purewash/privacy/

Before publishing / submitting to Google Play:
1. Confirm the public contact address info@publicvoid.win is yours and works.
2. Verify AdMob / Google Mobile Ads SDK and UMP behavior matches the policy.
3. Confirm app's local save/backup behavior matches the retention sentence.
4. Match Google Play Data Safety answers to all SDKs in the production AAB.
5. Add the final public URL to Play Console and the app Settings / Privacy Policy link.

The page uses local CSS only; no external scripts, trackers, fonts, or images.
